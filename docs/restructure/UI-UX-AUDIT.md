## 横切问题（多页共性）

1. **状态表达分散**：loading/空/错误/保存态各页自造（有 StateError/BatchBar 组件但未全覆盖）〔已验证组件存在〕。
2. **AI 操作披露不足**：扩库弹窗有 Token 提示✅，但改写/封面的"生成结果写到哪、可否撤销"披露不统一。
3. **响应式=隐藏列**（UI-GUIDE 5.1 + .col-optional）；文章预览 min-width 720px〔由 UI 方案指出，未独立验证〕。
4. **标题重复**（壳层 vs 页内）〔已验证〕。
5. **信息密度两极**：选题/文章表格承载内容型信息不足，模型/文风页又过载。
