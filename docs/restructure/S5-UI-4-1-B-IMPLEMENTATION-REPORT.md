## 6. 遗留问题与已知风险
- **标题右侧被固定操作列部分覆盖**：窄屏下选题内容列右侧 76px 被 fixed right 操作列遮挡，属 fixed 列预期行为，全文可 tooltip 查看；与 S5-UI-3-3 一致，非本轮缺陷。若未来要求标题全文在窄屏可见，需另立方案（如卡片式替代表格），不在本轮范围。
- **低优先级列在窄屏隐藏**：ID / 主题 / 用途 / 消费态「状态」（已用/未用）/ 关联文章 / 来源在 ≤1100px 隐藏。这些列的筛选能力仍在筛选条（状态/审核/用途/排序），数据可在详情/改稿页查看；桌面端完整保留。
- **断点 1100px**：与全局 `col-optional`(900px) 不同，本页独立断点；1024px 即进入紧凑模式（此时表格容器仅 870px，原 10 列总宽远超容器，审核/评分本就不可见，紧凑模式是必要改善）。
- **Mock 数据**：走查用手写夹具，不代表真实统计；但列布局、DOM 结构、fixed/响应式与 CSS 均为真实产物行为，几何结论与实际渲染一致。
