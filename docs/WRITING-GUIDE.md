# 公众号写作方法论（调研纪要 + 变体用法 + 查证/自检清单）

> 2026-11-11 两轮网络调研的沉淀，原为 WorkBuddy skill 内容；skill 已按用户要求移除，
> 方法论留档于此，供维护「文风配置」提示词与人工审稿时参照。生产写稿在 web 系统内闭环。

## 一、调研结论

### 标题设计（打开率 80% 看标题）
- 四个可组合要素：**数字**（3 个方法/100 篇）、**身份标签**（30 岁/二胎妈妈）、**结果承诺**（薪资翻倍）、**悬念/反常识**。
- 四类公式实测差异：数字清单型（稳定但易同质化）、反常识型（高但易标题党）、场景代入型（粘性高）、结果承诺型（必须兑现）。
- 前 15 个字抛出核心价值；带数字/疑问的标题打开率显著更高；情绪别过头。
- 生产顺序：**先定选题 → 再写标题 → 最后搭骨架**。起标题「先写 10 删 7」，前 3 个最平庸。

### 结构设计（决定完读率）
- 通用骨架：问题引入 → 观点 → 案例 → 方法总结 → 金句收尾；四大变体：故事型、清单型、反常识型、逻辑递进型。
- 开头 50-150 字下钩子（场景代入/扎心提问/数据冲击/反常识），禁寒暄；段落 2-4 行、2-4 个小标题；每约 300 字一个信息密度高点。
- 小标题间 400-600 字；结尾 = 金句 + 开放式互动提问；给读者一个转发理由。
- 完读率参考：一般 40-55%，干货 60%+ 优秀，低于 30% 说明开头绕或中段掉速。

### 文体（说人话）
- 当「同桌」不当「班主任」：先接住情绪再讲道理；「我教你」换「我陪你」。
- 短句为主、口语化、第一人称、**具体事替形容词**；不可替换细节 ≥3 处。
- 禁 AI 腔：综上所述/本质上/首先其次最后/宏大叙事开头；禁破折号、禁「不是X而是Y」类否定框架。
- 金句克制（红字 2-3 处，结尾最多 1 句）；引用必须带可检索出处（作者+来源+年份）。

### 正能量写法（核心要求）
- 三原则：**不放大痛苦、不制造焦虑、不吝啬希望**。情绪曲线「共鸣 → 希望 → 赋能」，不用「焦虑 → 卖解药」。
- 行动导向：给可带走的步骤/口诀/话术对照（「别说这句，说那句」）。
- 直面软肋但不强行正能量；少绝对化断言；揭现实也留一束光。

### 素材查证（写前，人工审稿时按此补验）
- 三重门：**来源权威**（官方机构/权威期刊，优先原始文献；预印本降级）→ **交叉验证**（≥2 独立信源）→ **时效性**（近 3 年且未废止）。
- AI 给的论文/数据/专家言论一律手动核查；查不到出处就不写。
- 逻辑链自检：不跳步、防滑坡谬误/虚假因果/断章取义；主动写明适用边界。

### 平台反模板化判定（第二轮调研）
- 微信推荐运营规范「低创作度内容」明文：短期高频发布**结构/框架/观点完全一致**的内容、**长期复用同一标题**、堆砌套话、**引用不存在的来源**、AI 套路批量灌水。2026 年起另有「非真人自动化创作」标签。
- 判定信号：语义重复率（约三成触发）；**开头/结尾/过渡段/总结段的固定句式**是重点扫描区；标题同质化直接判「信息增量低」；近 6-10 篇一个模子 = 账号模板化。
- 同质化内容展现量实测少约 80%；平台在意**信息增量**而非是否用 AI——全手写也会踩雷。
- 有效规避：标题公式/结构骨架/篇幅档逐篇轮换（已在系统内自动化）；每篇至少一处独家信息增量；标题正文对得上；稳定输出优于高频低质。

## 二、三维变体用法（已自动化，配置在「文风配置」页）

- 标题四类公式 / 结构四骨架 / 篇幅三档（`1400-1650|13-15` 短打 / `1800-2200|17-19` 标准 / `2150-2280|19-21` 长文）。
- 系统按游标逐篇轮换（标题/结构/篇幅各自取模），连续多篇不重样；篇幅档区间必须落在门禁 1300-2300 内。
- 人工审稿复核法：把近 6 篇放一起对照段落长度、句式节奏、开篇结尾模式是否雷同。

## 三、写后自检清单（人工审稿用）

**A 事实与逻辑**：引用都有出处；「有研究表明/专家发现」= 0；无杜撰案例；因果不跳步；边界已写明。
**B 正能量与读者视角**：无恐吓句；情绪曲线「共鸣→希望→赋能」；至少 1 个可带走的方法；无说教；结尾回扣具体物件 + 「你」提问。
**C 反模板化**：标题/结构/篇幅与上一篇不同档；开头钩子类型有变化；无固定句式；至少 1 处独家信息增量。
**D 文体与排版**：无破折号/否定框架/AI 腔；小标题 2-4 个；长短段混排；每 300 字一个密度高点；细节 ≥3 处；金句 2-3 处。
**E 标题终检**：前 15 字给核心价值；正文兑现承诺；候选里选的不是最平庸的。
